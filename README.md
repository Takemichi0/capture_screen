# macOS 自動スクリーンショット

macOS のメインディスプレイを定期的に撮影し、日付別のディレクトリへローカル保存するツールです。LaunchAgent により、初期設定では5分ごとに実行されます。

スクリーンショットを GitHub や外部サービスへアップロードする機能はありません。画像ディレクトリ、ログ、一時停止状態、ローカル設定は Git の管理対象から除外されます。

## 最短セットアップ

対象は macOS です。ターミナルを開き、次の3行をそのまま実行します。

```bash
git clone https://github.com/Takemichi0/capture_screen.git
cd capture_screen
./install.sh
```

インストール後、macOS から画面収録権限を求められた場合は、`システム設定 > プライバシーとセキュリティ > 画面収録` で許可します。権限を変更したら、次のコマンドでLaunchAgentを再登録します。

```bash
./install.sh
```

パスワード・秘密情報を扱うアプリを閉じた状態で、1回撮影して保存結果を開きます。

```bash
./capture.sh capture
open "$(date "+%Y-%m-%d")"
```

日付ディレクトリにPNG画像が表示されればセットアップ完了です。以後はMacへのログイン時に自動起動し、5分ごとにメインディスプレイを撮影します。

機密情報を表示する前は、必ず撮影を一時停止してください。

```bash
./capture.sh pause
```

撮影を再開する場合は次を実行します。

```bash
./capture.sh resume
```

撮影されない場合は、[撮影されない場合](#撮影されない場合)を確認してください。

## 安全性に関する重要な注意

このツールはメインディスプレイを自動撮影します。スクリーンショットには、パスワード、認証コード、個人的なメッセージ、金融情報、顧客情報、ソースコードなどの機密情報が含まれる可能性があります。

画面ロック中、ディスプレイのスリープ中、既知のパスワード・秘密情報を扱うアプリの起動中は撮影をスキップします。ただし、この判定によって機密情報が撮影されないことを保証するものではありません。ブラウザの入力フォーム、ターミナル、チャット、メール、クラウド管理画面、未登録のパスワード管理アプリなどは検知できません。

インストール前に、次の点を確認してください。

- 管理対象端末では、セキュリティポリシーが自動画面撮影を明示的に許可している場合だけ使用する
- パスワード関連アプリの検知をセキュリティ境界として信用しない
- 機密情報を表示する前に撮影を一時停止する
- ローカルアカウントを強いパスワードで保護し、FileVault を有効にする
- 古いスクリーンショットを定期的に確認して削除する
- 画像ディレクトリやログを `git add -f` で強制追加しない

## 必要環境

- macOS
- LaunchAgent をインストールできるユーザーアカウント
- `screencapture` を実行するプロセスへの画面収録権限

パッケージマネージャーやサードパーティー製ランタイムは必要ありません。

## インストールの仕組み

インストーラーは次の処理を行います。

1. クローン先の絶対パスを自動検出する
2. 現在のユーザー用に `~/Library/LaunchAgents/com.user.screencapture.plist` を生成する
3. 現在の GUI セッションへ LaunchAgent を登録する
4. 最初の撮影を開始する

macOS のバージョンによっては、画面収録権限の変更後にログアウトと再ログインが必要です。

### 撮影間隔を変更する

初期値は300秒です。別の間隔を使う場合は、正の秒数を指定してインストールします。

```bash
CAPTURE_INTERVAL_SECONDS=600 ./install.sh
```

撮影間隔やリポジトリの配置場所を変更した場合は、インストーラーを再実行してください。

## 使用方法

LaunchAgent はメインディスプレイを無音で撮影します。画像は現在のユーザーだけが読み書きできる権限で保存されます。

```text
capture_screen/
├── 2026-08-07/
│   ├── 2026-08-07_09-00-00.png
│   └── 2026-08-07_09-05-00.png
├── capture.sh
├── install.sh
└── uninstall.sh
```

### 機密情報を扱う前に一時停止する

```bash
./capture.sh pause
```

### 撮影を再開する

```bash
./capture.sh resume
```

### 一時停止状態を確認する

```bash
./capture.sh status
```

### 1回だけ撮影を試行する

```bash
./capture.sh capture
```

一時停止状態は、明示的に再開するまで維持されます。ログアウトや再起動を行っても自動的には解除されません。

## 自動的に撮影をスキップする条件

次のいずれかに該当する場合、定期撮影をスキップします。

- `./capture.sh pause` で一時停止している
- macOS セッションが画面ロック中と判定されている
- ディスプレイがスリープまたは省電力状態になっている
- 次のパスワード・秘密情報を扱うプロセスが起動している
  - 1Password
  - Bitwarden
  - Keeper
  - LastPass
  - キーチェーンアクセス
  - メモ

パスワード関連アプリの検知では、現在表示中のウィンドウではなくプロセス名を確認します。このため、登録済みアプリがバックグラウンドで動作しているだけでも、すべての定期撮影がスキップされる場合があります。反対に、ブラウザや未登録アプリに表示されたパスワードや機密情報は撮影される可能性があります。

## 撮影されない場合

最初に次を確認します。

1. `./capture.sh status` が `Capture is enabled.` を表示する
2. 画面がロックされていない
3. ディスプレイがスリープしていない
4. 登録済みのパスワード関連アプリが起動していない
5. macOSの画面収録権限が許可されている

権限を変更した場合は、LaunchAgentを再登録します。

```bash
./install.sh
```

### LaunchAgent の確認

launchd にサービスが登録されているか確認します。

```bash
launchctl print "gui/$(id -u)/com.user.screencapture"
```

撮影されない場合はローカルログを確認します。

```bash
tail -50 capture.log
tail -50 launchagent_stderr.log
```

主な原因は、画面収録権限がない、一時停止中、登録済みのパスワード関連アプリがバックグラウンドで動作中、画面ロック中、ディスプレイスリープ中などです。

## 保存容量と削除

PNG スクリーンショットは多くのディスク容量を使用する可能性があります。このバージョンには古い画像の自動削除機能がありません。定期的に使用量を確認してください。

```bash
du -sh ./20??-??-?? 2>/dev/null | sort -h
```

日付ディレクトリを削除する前に、対象と内容を必ず確認してください。確認していない広範囲な `rm -rf` コマンドは実行しないでください。

## アンインストール

LaunchAgent を停止し、自動生成した plist を削除します。

```bash
./uninstall.sh
```

アンインストールしても、既存のスクリーンショットとログは削除されません。内容を確認したうえで個別に削除してください。

画面収録権限は macOS が管理するため、自動的には削除されません。不要になった場合は、`システム設定 > プライバシーとセキュリティ > 画面収録` から手動で解除してください。

## プライバシーと Git 履歴

生成された画像ディレクトリ、ログ、一時停止状態、ローカル設定は `.gitignore` で除外されています。変更をプッシュする前に、Git の管理対象を確認してください。

```bash
git status
git ls-files
```

日付ディレクトリやログに `git add -f` を使用しないでください。Private リポジトリを Public に変更すると、現在のファイルだけではなく、参照可能な Git 履歴内の全ファイルが公開されます。
